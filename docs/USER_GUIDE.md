## 1. 开机与预热

### 上电

使用 5V USB 电源（电脑 USB 口或充电宝）为设备供电。上电后设备会自动启动并显示主界面。

### 预热

开机后状态栏显示 **`WARM UP`**（蓝色），此时：

- 界面显示**预热剩余秒数**，倒计时 **180 秒**
- 设备**不会报警**（这是有意设计，避免刚上电时传感器输出不稳定导致误报）
- LED 以 1 秒周期慢闪

倒计时结束后状态变为 **`NORMAL`**（青色），LED 转为常亮，此时读数可信。

> **为什么需要预热**
> MQ-7 属于半导体式气体传感器，内部加热丝需要将敏感材料加热到工作温度后输出才稳定。
>
> | 阶段 | 时间 | 状态 |
> |---|---|---|
> | 加热到位 | 约 30 秒 | 输出开始有反应 |
> | 读数可用 | **3~5 分钟** | 相对变化可信（设备默认 180 秒） |
> | 完全稳定 | 24~48 小时 | 首次使用建议连续通电老化 |
>
> **全新传感器建议第一次连续通电 24~48 小时**后再进行标定，之后读数会明显更稳定。

## 2. 触摸校准（仅首次）

如果 EEPROM 中没有保存过校准参数（例如首次使用或更换屏幕），开机会自动进入触摸校准流程。

### 操作步骤

屏幕上会依次出现 **4 个十字光标**，位置如下：

```
①                                       ②
左上角                              右上角

③                                       ④
左下角                              右下角
```

**用手指或触控笔依次点准每个十字的中心**。每点准一个，该十字消失并出现下一个。

### 注意事项

| 事项 | 说明 |
|---|---|
| 必须点准中心 | 点偏会导致后续触摸坐标整体偏移，按键点不中 |
| 点击有延迟是正常的 | 程序需要检测"按下 → 抬起"的完整动作 |
| 如果点错 | 校准会自动检测四个点的距离是否合理，不合理会重新开始 |
| 超时退出 | 连续 10 秒未操作会自动退出校准，重启即可重新校准 |

校准完成后参数写入 EEPROM，**以后开机不再询问**。

### 需要重新校准的情况

- 点击按键位置明显偏移、点不中
- 更换了显示屏或触摸屏
- EEPROM 数据异常

## 3. 传感器标定

> **这是使用前必须完成的步骤。不做标定，CO 读数没有参考意义。**

### 为什么必须标定

MQ-7 传感器出厂时个体差异较大，程序内置的换算曲线使用的是手册典型值。标定的作用是**测量你这颗传感器的基准电阻 R0**，让读数贴合实际。

### 标定步骤

| 步骤 | 操作 | 检查点 |
|---|---|---|
| 1 | 上电并等待预热完成 | 状态显示 `NORMAL`（不是 `WARM UP`） |
| 2 | 把设备放到**洁净空气**中 | 室外通风处，或刚开过窗的房间 |
| 3 | 确认环境无干扰源 | 无酒精、香水、香烟、燃气灶、汽车尾气 |
| 4 | 点击屏幕下方的 **`CAL`** 键 | 主界面的 `R0` 数值发生变化 |
| 5 | 标定完成 | 数值已自动写入 EEPROM，掉电不丢 |

### 洁净空气的判断

| 环境 | 是否可以 |
|---|---|
| 室外通风处、阳台 | ✅ 推荐 |
| 刚开窗通风的室内 | ✅ 可以 |
| 关窗的室内（有人在） | ⚠️ 勉强，CO₂ 与人呼气会影响 |
| 厨房、车库、刚喷过酒精的房间 | ❌ 绝对不能 |

### 标定错误的后果与处理

如果在污染环境中误点 `CAL`，R0 会被标定得偏小，导致**之后所有读数都偏低**（该报警时可能不报警）。

**处理方法**：到洁净空气中重新标定一次即可覆盖，无需其他操作。

### 验证标定是否合理

标定后，在洁净空气中：

- CO 读数应当在 **0 ~ 5 ppm** 之间
- 主界面 `Vout` 一般在 **0.3 ~ 0.9V** 范围
- 对着传感器哈一口气，读数应明显上升

若偏差很大，请检查接线（见 [README 接线说明](../README.md#接线说明)）。

## 4. 界面读数详解

```
┌──────────────────────────────────────────────────────────┐
│ [NORMAL]          CO MONITOR           [电池] 100%       │
├──────────────────────────────────────────────────────────┤
│  CO                              ┌ TREND ────────────┐   │
│  1.4         ppm                 │   实时浓度曲线     │   │
│  air looks clean                 └───────────────────┘   │
│  TEMP 28 C      HUMI 44 %RH                              │
│  Vout 0.67V     UP 00:09      LOG 11                     │
├──────────────────────────────────────────────────────────┤
│      [ MAIN ]        [ LOG ]        [ CAL ]              │
└──────────────────────────────────────────────────────────┘
```

| 显示项 | 含义 | 正常范围 |
|---|---|---|
| **状态胶囊** | 设备当前状态 | 预热完成后应为 `NORMAL` |
| **CO 读数** | 一氧化碳浓度，单位 ppm | 洁净空气 0~5 ppm |
| **air looks clean** | 系统给出的操作建议 | 随状态变化 |
| **TREND 曲线** | 最近 40 次采样的浓度趋势 | 平直表示环境稳定 |
| **TEMP** | 环境温度（℃） | DHT11 量程 0~50 ℃ |
| **HUMI** | 相对湿度（%RH） | DHT11 量程 20~90 %RH |
| **Vout** | MQ-7 输出电压 | 洁净空气约 0.3~0.9V |
| **UP** | 开机运行时长（分:秒） | 同时作为日志时间戳 |
| **LOG** | EEPROM 中累计日志条数 | 每次报警 +1 |
| **电池图标** | 剩余电量百分比 | 低于 3.5V 变色提示 |

### 读数含义对照

| CO 浓度 | 状态 | 建议 |
|---|---|---|
| 0 ~ 25 ppm | `NORMAL` | 环境正常 |
| 25 ~ 50 ppm | `WARNING` | 开窗通风 |
| > 50 ppm | `ALARM` | ⚠️ 立即开窗并离开 |

### 关于读数的准确性

MQ 系列属于**民用级传感器**，请注意：

- 绝对误差可能在 **±30%** 量级
- 受环境温湿度影响明显
- 会随使用时间缓慢漂移（建议定期重新标定）
- **关注趋势变化比关注绝对数值更可靠**

## 5. 按键操作

界面底部有三个触摸按键：

| 按键 | 功能 | 说明 |
|---|---|---|
| **MAIN** | 返回主界面 | 从日志页切回读数界面 |
| **LOG** | 查看日志 | 显示最近 6 条报警记录 |
| **CAL** | 传感器标定 | ⚠️ 仅在洁净空气中操作，见[第 3 节](#3-传感器标定) |

> **提示**：`CAL` 会直接执行标定，请确认环境后再点击。

### 板载按键

| 按键 | 位置 | 功能 |
|---|---|---|
| 红色复位键 | 板上标 `RST` | 重新启动设备 |
| KEY0 / KEY1 / KEY2 | 板上丝印 | 当前版本未分配功能 |

## 6. 报警说明

### 报警逻辑

设备采用**双阈值 + 迟滞 + 持续时间确认**的设计，避免误报和频繁跳变：

| 项目 | 阈值 | 说明 |
|---|---|---|
| 预警触发 | 25 ppm | 状态变为橙色 `WARNING` |
| 预警解除 | 18 ppm | 迟滞，避免在 25 ppm 附近反复跳变 |
| 报警触发 | 50 ppm | 需**连续超过 3 秒**才确认 |
| 报警解除 | 40 ppm | 迟滞 |

> **为什么要 3 秒确认**：划一根火柴、喷一下打火机气体都会让读数瞬间冲高，但不构成真实事故，因此设置确认时间过滤瞬时干扰。

### 报警表现

| 状态 | 屏幕 | LED |
|---|---|---|
| `WARNING` | 状态胶囊变橙，读数变橙，曲线变橙 | 0.4 秒周期闪烁 |
| `ALARM` | 状态胶囊变红，读数变红，**读数卡边框呼吸发光** | 0.2 秒周期急促闪烁 |

### 报警后怎么办

1. **立即开窗通风**，人员离开该区域
2. 观察读数是否下降
3. 若持续报警，检查是否有燃气泄漏等真实隐患
4. 浓度回落到解除阈值以下后，状态自动恢复正常

> ⚠️ **本设备为学习实践作品，不可作为安全防护依据。** 涉及人身安全请使用经计量认证的专业仪器。

## 7. 日志查看

点击 **`LOG`** 键进入日志页：

```
TIME    CO    T   EVENT
  0:01   62   26  CO ALARM
  0:00    0   26  power on
  ---- total 2 records ----
```

| 字段 | 含义 |
|---|---|
| `TIME` | 开机运行时长（分:秒）。设备无 RTC 电池，关机后归零 |
| `CO` | 事件发生时的 CO 浓度（ppm） |
| `T` | 事件发生时的温度（℃） |
| `EVENT` | 事件类型 |
| `total` | EEPROM 中累计日志总条数 |

### 事件类型

| 显示 | 含义 |
|---|---|
| `power on` | 开机记录 |
| `CO warn` | 触发预警 |
| `CO ALARM` | 触发报警 |
| `LOW BATT` | 低电量 |
| `SENS ERR` | 传感器异常 |

### 记录规则

| 触发条件 | 是否记录 |
|---|---|
| 状态发生变化（进入预警 / 报警 / 异常） | ✅ 记录一条 |
| 报警持续中 | ✅ 每 10 分钟补记一条 |
| 低电量首次出现 | ✅ 记录一条 |
| 报警持续期间 | 不再重复记录，避免频繁擦写 |

### 容量

最多保存 **32 条**，写满后**自动覆盖最旧的记录**（环形缓冲）。

> 日志存储在 24C02 EEPROM 中，**掉电不丢失**。

## 8. 电池与供电

### 供电要求

| 项目 | 要求 |
|---|---|
| 电压 | 5V |
| 电流 | ≥ 500mA（整机约 400mA） |
| 接口 | USB |

### 功耗构成

| 部件 | 电流 |
|---|---|
| MQ-7 加热丝 | 约 150 mA |
| 屏幕背光 | 约 150 mA |
| 主控与外围 | 约 60 mA |
| **合计** | **约 400 mA** |

### 使用充电宝供电

可以直接用充电宝为设备供电，适合便携使用。注意事项：

| 事项 | 说明 |
|---|---|
| 优先用 USB-A 口 | 输出稳定 5V |
| ❌ 避免快充 Type-C 口 | 可能输出 9V/12V，会损坏设备 |
| 自动关机问题 | 部分充电宝检测到小电流会自动断电，请切换到"小电流模式" |
| **拔掉 ST-Link** | 充电宝与 ST-Link 同时供电会互相冲突 |

### 电量显示

| 电量 | 图标颜色 |
|---|---|
| > 50% | 青色 |
| 20% ~ 50% | 橙色 |
| < 20% | 红色 |
| 低于 3.5V | 额外记录 `LOW BATT` 日志 |

电量百分比按锂电池放电曲线查表换算，比简单的电压线性换算更准确。

## 9. 常见问题

### 显示类

**Q：屏幕全白 / 花屏**

| 可能原因 | 处理方法 |
|---|---|
| 排线松动 | 断电后重新插紧 TFT 排线（两头都要检查） |
| 供电不足 | 换用带独立供电的 USB 口或充电宝 |
| PB3/PB4 未释放 | 程序已处理，若自行修改过 `main.c` 请确认 `KEY_Init()` 在屏幕初始化前调用 |

**Q：屏幕亮但界面卡住不动**

LVGL 图形内存不足会导致死循环。请确认 `lv_conf.h` 中 `LV_MEM_SIZE` 为 24KB，修改后**必须重新完整编译**（`build.bat clean` 后 `build.bat`）。

**Q：屏幕很暗**

供电不足。MQ-7 加热丝耗电较大，请使用充电宝或带独立供电的 USB 口。

### 触摸类

**Q：点击按键没反应或点不准**

触摸校准数据不准确。断电重启后重新校准（参考[第 2 节](#2-触摸校准仅首次)）。

**Q：触摸完全无反应**

确认是**电阻屏**。程序对电容屏和电阻屏分别处理，若屏幕型号不符请检查串口输出的 `LCD ID`。

### 传感器类

**Q：CO 读数一直是 0.0**

| 检查项 | 方法 |
|---|---|
| MQ-7 是否供电 | 模块上的电源指示灯是否亮 |
| AO 是否接到 PA1 | 检查接线 |
| 看 `Vout` 数值 | 若始终为 0.00V，说明 ADC 没读到信号 |

**Q：CO 读数异常偏高**

| 可能原因 | 处理方法 |
|---|---|
| MQ-7 接到了 3.3V | **必须接 5V** |
| 刚上电还没预热完 | 等待 3 分钟 |
| 未标定或标定错误 | 在洁净空气中重新点 `CAL` |
| 环境中有干扰源 | 移到通风处观察 |

**Q：温湿度显示 `--`**

| 可能原因 | 处理方法 |
|---|---|
| 缺少上拉电阻 | DHT11 的 DATA 与 VCC 之间需要 4.7k~10k 电阻 |
| 接线错误 | DATA 应接 PA3 |
| 采样间隔过短 | 程序已限制为 2 秒一次，无需处理 |

**Q：温湿度偶尔显示 `--` 又恢复**

DHT11 偶发读取失败属于正常现象，程序会保留上一次的有效值，不影响使用。

### 报警类

**Q：开机就报警**

预热期间不会报警。若预热后立即报警，说明环境中确实存在 CO 或标定值不合理。请检查 `R0` 数值是否正常。

**Q：设备不报警但环境中明显有异味**

| 可能原因 | 处理方法 |
|---|---|
| MQ-7 只对 CO 敏感 | 酒精、香水、燃气等不一定含 CO，**这是传感器特性决定的** |
| 标定值偏大 | 在洁净空气中重新标定 |
| 未预热完 | 等待 3 分钟 |

### 数据类

**Q：日志丢失 / 重置**

| 可能原因 | 处理方法 |
|---|---|
| 24C02 通信异常 | 检查 PC11/PC12 是否被占用 |
| 日志超过 32 条 | 环形缓冲会覆盖最旧记录，属于正常行为 |

## 10. 维护建议

| 周期 | 项目 |
|---|---|
| 每次使用前 | 预热 3 分钟，观察读数是否正常 |
| 每周 | 在洁净空气中验证读数是否接近 0 ppm，偏差大则重新标定 |
| 每月 | 检查接线是否松动，清洁传感器防尘网 |
| 长期存放后 | 重新通电老化数小时后再使用 |

### 传感器保养

| 事项 | 说明 |
|---|---|
| 避免高浓度气体直冲 | 会用敏感材料"中毒"，导致读数长期偏高 |
| 避免酒精/香水接触 | 同上 |
| 避免结露 | 高湿环境使用后应通风干燥 |
| 存放环境 | 常温干燥处 |

### 设备寿命

MQ-7 传感器为**消耗品**，长期使用后灵敏度会衰减。若发现以下情况，建议更换传感器模块：

- 洁净空气中读数持续偏高，重新标定后仍然如此
- 对已知 CO 源的反应明显变弱
